# Maintenance audit — 2026-10-16

Reviewed all Java source files, all configuration/metadata resources, Gradle settings/build/wrapper and tracked generated files. Legacy ConfigUtil and ReloadCommand remain for binary compatibility; favicon validation is shared with the active loader. No command dispatches privileged proxy or backend console commands. Management commands check individual permissions or admin. Permission inheritance was reversed to prevent escalation.

Validation: JUnit regression tests cover cooldown expiry, maintenance toggles, malformed/object-tagged/duplicate YAML rollback, per-profile/disabled fake counts, static overrides, integer overflow, random range overflow, truncated hex, favicon traversal/dimensions/data, MiniMessage rendering and permission inheritance. Actual local runtime tests passed on BungeeCord 2104, Velocity 4.2.0 build 30 and Paper 26.3 build 194: startup, protocol 777 status responses, MOTD, hover, PNG favicon, online counts, maintenance on/off, fake-player override, invalid reload rollback, valid reload and shutdown.

Tests used loopback listeners and offline authentication. Authentication services, upstream version checks and proxy module downloads are outside plugin validation; some upstream requests were unavailable in this environment. The malformed-reload test intentionally logs a rejected YAML error. No claim is made for online authentication, vanilla Spigot, Folia, Waterfall, older Minecraft versions, live players or high-load performance. Those require further runtime testing.

Current upstream: Mojang manifest release 26.3; Paper stable 26.3/194; Velocity stable 4.2.0/30 (4.2.1-SNAPSHOT excluded); Bungee successful build 2104 supports protocol 777. Waterfall is discontinued.
